## Medium Description (one paragraph)

```
Your memory is scattered across a dozen tools, and none of them talk to each other. TideMind is an open-source memory layer that connects all your AI tools and note systems into a single living knowledge graph. At the start of every conversation, your AI receives a complete profile distilled from all past interactions. When it needs more context, it navigates the graph link by link — from a decision to the discussion behind it, then to changes it triggered — rather than guessing keywords. Behind the scenes, a metabolism system runs continuously: inactive memories decay naturally, divergent scanning discovers hidden connections between unlinked ideas, and important patterns crystallize into distilled representations of how you think. Inspired by 80 years of cognitive science — from Bush's Memex to modern memory reconsolidation research. Works with Claude Code, Cursor, Windsurf, Codex, and any MCP-compatible tool. Syncs with Obsidian, Logseq, and Apple Notes. All data lives in a local SQLite file on your machine.
```

## Feature Bullets

```
- Unified memory across all AI tools — Claude, Cursor, Windsurf, Codex all share the same knowledge graph
- Complete user profile delivered at the start of every conversation — every AI knows you completely
- Graph-navigating recall — follows links between memories on demand, not just keyword/vector top-K
- Living metabolism: memories decay naturally, divergent scanning discovers hidden connections, important patterns crystallize
- Three cognitive operations (prepare / recall / digest) — not CRUD, modeled after how biological memory works
- Note sync from Obsidian, Logseq, and Apple Notes — notes and AI conversations cross-pollinate in one graph
- 100% local — single SQLite file, exportable to Markdown anytime, no cloud, no vendor lock-in
- Flexible LLM: Anthropic, Google, or fully local with Ollama — mix and match as you like
- MCP-native — standard protocol, works with any MCP-compatible tool out of the box
- Inspired by 80 years of cognitive science, from Bush's Memex to modern reconsolidation research
```
